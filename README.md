 Análisis de salud mental con Spark

En este trabajo se realiza el análisis de un dataset de estudiantes con más de 1 millón de registros.

Se utiliza Apache Spark para procesar los datos y obtener resultados como:
- Identificación de estudiantes con alto nivel de estrés
- Análisis de burnout académico
- Estadísticas por año y género

Este proyecto hace parte de una actividad académica donde estoy aprendiendo sobre Big Data.
